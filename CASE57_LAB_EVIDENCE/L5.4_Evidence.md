# L5.4 – Project Validator and AI-Reference Validator Comparison

## Scope and authorship

The project validator is treated as the **project baseline**; its original human authorship was not independently verified in this session. The comparison function below is an AI-generated reference authored by the Copilot SDK assistant for this lab. It is not inserted into application source.

```python
def ai_reference(d, w, r):
    values = (d, w, r)
    if any(value < 0 for value in values):
        raise ValueError("Duty hours and rest hours cannot be negative.")
    rules = (
        (d > 10, "Daily duty limit exceeded."),
        (r < 10, "Minimum rest requirement not met."),
        (w > 60, "Weekly duty limit exceeded."),
    )
    for invalid, reason in rules:
        if invalid:
            return False, reason
    return True, "Duty schedule accepted."
```

## Additional local execution-time measurement

The same ten recorded inputs were also executed against both functions in the configured local Python 3.14.7 environment. The two functions matched the same result category on all **10/10** cases. A small repeated-call benchmark was run as five alternating samples to reduce order bias: each sample invoked each function 5,000 times for each of the ten cases (50,000 calls per sample). The observed elapsed times were:

| Implementation | Five samples (ms) | Median (ms) |
|---|---|---:|
| Project validator | 40.997, 39.496, 39.602, 41.125, 39.597 | 39.602 |
| AI reference | 37.529, 40.382, 39.386, 38.959, 38.768 | 38.959 |

These are short-run in-process function timings, not authoring times. The small observed difference is not evidence of a meaningful performance advantage: the functions are tiny, host scheduling/noise affects millisecond measurements, and no confidence/production-scale study was performed. The benchmark does not exercise concurrent users or 400-crew scheduling.
