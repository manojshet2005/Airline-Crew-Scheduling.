# L4.4 – AI-Test Validation, Accuracy, and Final Set

## Source and evaluation rule

The actual ChatGPT prompt/output and execution of its first ten cases are preserved in `L1.5_Evidence.md`. This lab checks whether the expected results are supported by the Case 57 sample rule table, not whether the current implementation happens to pass.

The sample table explicitly covers the inclusive 10-hour daily, 10-hour rest and 60-hour weekly limits, first-violation order (daily, rest, weekly), and rejection of negative inputs. It does not specify a Boolean type policy. ChatGPT's TC10 expected `ValueError` for `True` is therefore unsupported by the case rule table and is classified as wrong/extra for this lab, even though the detailed ChatGPT prompt asked for Boolean rejection.
