# L4.5 – Monitoring Dashboard Design

## Requirement and existing evidence

The official lab requires a dashboard design with six metrics, thresholds, alert actions and a sketch. The existing image `C57_L4.5_01_Dashboard_Sketch.png.png` was inspected and contains six metric cards, threshold/action labels and a recent-alerts table.
