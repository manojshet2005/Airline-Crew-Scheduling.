# L1.3 – Same Prompt in ChatGPT and Copilot

## Exact shared prompt

This prompt was submitted in the user-shared ChatGPT conversation **“Write Duty Validator.”** The same text was used for the Copilot SDK assistant response documented below.

> Context: This is a small educational prototype for Case 57, airline crew scheduling. The limits below are configurable sample values only, not confirmed aviation law. Task: write one self-contained Python 3 function `validate_duty(hours_today, hours_last_7_days, rest_hours)`. Rules and required behavior: daily duty must be <= 10 hours; rest must be >= 10 hours; rolling seven-day duty must be <= 60 hours. Equality at each boundary is valid. Inputs may be int or float, but must be finite and non-negative. Reject bool explicitly (it is an int subclass), strings, other types, NaN, infinity, and negative values with ValueError. Do not silently coerce inputs. Return exactly `(is_valid, reason)` with a bool and a concise, stable human-readable string. For simultaneous rule violations, report the first in this order: daily, rest, rolling seven-day. Include Python type annotations and a useful docstring that labels limits as sample rules. Use only the standard library. Do not mutate inputs, add dependencies, access external services, or claim to run tests or modify the existing project. Output format: (1) code only in one Python code block, (2) a compact table of cases and expected outcomes covering exact valid boundaries, just-over/under-boundary violations, simultaneous violations, negative, bool, string, NaN and infinity, and (3) a brief note about assumptions. Ensure examples follow the implementation exactly.

### Copilot SDK assistant in VS Code

This response was generated in the current Copilot SDK session:

```python
import math


def validate_duty(hours_today, hours_last_7_days, rest_hours):
    values = (hours_today, hours_last_7_days, rest_hours)
    for value in values:
        if (
            type(value) not in (int, float)
            or (isinstance(value, float) and not math.isfinite(value))
            or value < 0
        ):
            raise ValueError("Inputs must be finite, non-negative numbers.")

    checks = (
        (hours_today > 10, "Daily duty exceeds 10 hours."),
        (rest_hours < 10, "Rest is below 10 hours."),
        (hours_last_7_days > 60, "Rolling 7-day duty exceeds 60 hours."),
    )
    for violated, reason in checks:
        if violated:
            return False, reason
    return True, "All sample duty rules satisfied."
```

The Copilot response uses only the standard library, validates before evaluating rules, and implements the same precedence. It omits the type annotations and docstring requested in the prompt; this is a clarity/completeness difference from ChatGPT's output.
