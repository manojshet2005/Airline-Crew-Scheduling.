# L2.3 – MoSCoW and Value-versus-Effort Prioritisation

## Scope and method

The four existing backlog stories are reused, with four additional proposed stories to reach the required minimum of eight. Priorities and scores below are a documented planning judgment, not a team vote or measured project data. Value and effort use a 1–5 scale; value-per-effort is `value / effort`.

## Difference between views

MoSCoW expresses release necessity: US-08 is explicitly deferred because the current prototype does not generate rosters. Value/effort can rank a deferred feature differently because its potential value is high, but its estimated effort is also high. The ratio is a prioritization aid, not a substitute for safety or stakeholder decisions.
