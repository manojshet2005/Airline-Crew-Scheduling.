### Simulated acceptance criteria and outcome

1. Equality at each sample boundary is accepted.
2. Each individual sample-rule violation produces its specific reason.
3. Missing, negative, Boolean, non-numeric, and non-finite API values are rejected as input errors.
4. The interface visibly identifies the limits as educational assumptions.
5. Operational use remains blocked until an authorized rule source defines duty-day, rest-period, rolling-window, and time-zone semantics.
