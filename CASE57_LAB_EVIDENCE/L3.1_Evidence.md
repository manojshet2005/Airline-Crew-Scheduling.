## Prompt 3 – Input validation, type hints, and sample-rule caveat

### Actual prompt

> Write a Python function named validate_duty(hours_today, hours_last_7_days, rest_hours) for an airline crew duty validator. Return (is_valid: bool, reason: str) and report the first violation in this order: daily duty, rest, rolling 7-day duty. Include type hints, a docstring that labels the rules as sample rules rather than confirmed law, and runnable examples for valid boundaries, each violation, negative input, and a bool input. Use only the Python standard library. Do not modify or claim to have tested any existing project files.

### Actual ChatGPT output

ChatGPT introduced the response as a complete Python standard-library implementation and returned:

```python
import math

def validate_duty(
    hours_today: int | float,
    hours_last_7_days: int | float,
    rest_hours: int | float
) -> tuple[bool, str]:
    """
    Validate airline crew duty hours.

    Sample rules (not confirmed aviation law):
    1. Daily duty must not exceed 10 hours.
    2. Rest between duties must be at least 10 hours.
    3. Rolling 7-day duty must not exceed 60 hours.
    Equality at the limits is allowed.

    Raises:
        ValueError: If any input is not a finite, non-negative integer or
        float (excluding bool).

    Returns:
        tuple[bool, str]: Validation result and reason.
    """
    values = [hours_today, hours_last_7_days, rest_hours]

    # Validate input types and values
    for value in values:
        if isinstance(value, bool) or not isinstance(value, (int, float)):
            raise ValueError("All inputs must be finite non-negative numbers.")
        if not math.isfinite(value) or value < 0:
            raise ValueError("All inputs must be finite non-negative numbers.")

    # Rule 1: Daily duty
    if hours_today > 10:
        return False, "Daily duty exceeds 10 hours."

    # Rule 2: Minimum rest
    if rest_hours < 10:
        return False, "Rest between duties is less than 10 hours."

    # Rule 3: Rolling 7-day duty
    if hours_last_7_days > 60:
        return False, "Rolling 7-day duty exceeds 60 hours."

    return True, "Duty requirements satisfied."

# Runnable examples
if __name__ == "__main__":
    # 1. Valid boundary values
    print(validate_duty(10, 60, 10))

    # 2. Daily duty violation
    print(validate_duty(11, 50, 12))

    # 3. Rest hours violation
    print(validate_duty(8, 50, 9))

    # 4. Rolling 7-day duty violation
    print(validate_duty(8, 61, 12))

    # 5. Negative input
    try:
        print(validate_duty(-1, 50, 12))
    except ValueError as e:
        print("ValueError:", e)

    # 6. Boolean input
    try:
        print(validate_duty(True, 50, 12))
    except ValueError as e:
        print("ValueError:", e)
```

ValueError: All inputs must be finite non-negative numbers.
